Mock issuers

Part of the personal agent kit: the places a person’s certificate tokens come from. An employer, a shop, a bank, a maker, a ticket office. A business agent issues certificate tokens the same way (see company.js). Signing code: core/paper.js.

How the signing works, like https

  1. The issuer makes a key pair once and keeps the secret key in its own system, as a website keeps its certificate key.
  2. A registry checks the issuer once and signs a key note: this issuer, at this web address, has this key. That is what a certificate company does for a website.
  3. Every certificate token the issuer signs carries its key note, and is issued to one agent’s key.
  4. The middle ground keeps a short public list of registries it trusts, like a browser’s list of certificate companies, and checks each token offline: registry → key note → certificate token → this agent.

Here the registry is the Sample Business Registry, test only: its secret key is public in samples.js, so this page can play it.
